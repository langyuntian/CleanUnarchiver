第三方开源组件许可声明
======================
干净解压工具 CleanUnarchiver 使用了以下第三方开源组件。其版权归各自作者所有，本声明随软件一并分发，满足各组件许可的再分发要求。

组件清单
--------
| 组件 | 用途 | 许可类型 |
|------|------|----------|
| py7zr | 7z 解压 | LGPL-2.1-or-later / MIT 双许可（以实际发布版本为准） |
| rarfile | RAR 解压接口 | ISC 类许可 |
| pyzstd | Zstandard 解压 | BSD-3-Clause |
| lz4 | LZ4 解压 | BSD-2-Clause |
| pyzipper | WinZip AES 加密 zip 解压 | MIT |
| pycryptodomex | AES 加解密支持 | 公有领域（Public Domain）+ BSD 双许可（以实际版本为准） |
| tkinterdnd2 | 拖拽支持 | MIT |
| Pillow (PIL) | 图标生成 | HPND / MIT-CMU |
| UnRAR（RARLAB 官方免费版） | RAR 解压 | RARLAB Freeware（见 UnRAR_LICENSE.txt） |
| expand.exe | CAB 解压 | Windows 系统自带组件（微软） |

说明
----
1. 各组件以「不改动、按原许可分发」方式静态/动态集成进本软件，功能均为**解压**用途，不包含 RAR 等专有压缩算法的反向工程。
2. 如需组件的完整许可全文，可访问各组件官方仓库或联系权利人索取。
3. 本软件整体著作权及知识产权归深圳市研融科技有限公司所有。

本声明随干净解压工具一起分发。
