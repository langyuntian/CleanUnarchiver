## 为什么选择干净解压工具

- **全本地运行**：不联网、不上传、不弹广告、无捆绑，代码完全可审阅。
- **格式支持广**：`zip`、`7z`、`rar`、`tar`、`tar.gz`、`tar.bz2`、`tar.xz`、`tar.zst`、`tar.lz4`，单文件 `gz` / `bz2` / `xz` / `zst` / `lz4`，以及 Microsoft `cab`。
- **AES 加密 zip**：支持解压 WinZip AES-256 加密的 zip（输入密码）。
- **拖拽即解压**：把压缩包直接拖进窗口即可，支持多文件批量。
- **智能识别**：先按扩展名、再按文件头（magic bytes）自动判断格式。
- **文件校验**：检测文件内容真实格式，与扩展名比对并标注是否一致，动态匹配解压工具（可识别「伪装/改名的 .rar 实为 ZIP」等异常文件）。
- **加密压缩包**：支持输入密码解压加密的 zip / 7z。
- **安全防护**：内置「路径穿越」拦截，防止恶意压缩包解压到目标目录之外。
- **实时进度 + 解压日志**：解压过程清晰可见。
- **右键菜单 / 默认解压工具**：安装后可在右键一键解压，并可选设为系统默认解压工具。

前往 **Releases** 页面下载 Windows 安装包：

## 安装引导

1. 从 Releases 下载安装包并保存到本地；
2. 双击安装包，**若弹出「Windows 已保护你的电脑 / 未知发布者」**：
   - 点击「**更多信息**」→ 点击「**仍要运行**」；
3. 按中文向导完成安装（可勾选/取消「右键菜单」「设为默认解压工具」「桌面快捷方式」等附加任务）；
4. 完成后即可使用；卸载可在系统「设置 → 应用」中完成，卸载会自动清理右键菜单与文件关联。

## 使用方法

- **图形界面**：双击运行，把压缩包拖入窗口，或点击「添加文件」→「开始解压」；
- **右键菜单**（安装后）：对压缩包右键 →「用 干净解压工具 解压到当前目录 / 解压到同名文件夹」；
- **命令行**：
  ```
  CleanUnarchiver.exe --extract-here "某.zip"    # 解压到压缩包所在目录
  CleanUnarchiver.exe --extract-into "某.zip"    # 解压到压缩包同名的子文件夹
  ```
- **文件校验**：在主界面点「校验文件」，查看每个文件的真实格式与扩展名是否一致。

## 从源码运行 / 构建

需要 Python 3.10+，安装依赖：
```
pip install py7zr rarfile tkinterdnd2 Pillow pyzstd lz4 pyzipper pycryptodomex
```
运行：`python 干净解压工具.py`（或双击 `启动解压工具.bat`）。

打包与安装程序构建方法见 `setup_cleanunarchiver.iss` 与各脚本注释。
